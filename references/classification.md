# 面试题分类体系

## 维度 A：技术领域

### 1. 评测（Evaluation）
- LM-as-Judge 方法论
- Agent 评测
- 评测工程化与可靠性
- 人工评测与自动化评测对齐

### 2. RAG（检索增强生成）
- Chunking 策略
- 向量检索与召回优化
- Query 理解与改写
- 多模态 RAG
- RAG 评测

### 3. Agent 架构与框架
- Agent 架构设计
- 工具调用与参数传递
- 多 Agent 协同
- Agent 规划与推理
- Agent 记忆系统

### 4. Prompt Engineering
- Prompt 设计原则
- Few-shot 与 CoT
- Prompt 优化与迭代
- Prompt 安全与鲁棒性

### 5. 模型训练与微调
- 预训练基础
- SFT（监督微调）
- RLHF / DPO
- 领域适配
- 数据工程

### 6. 部署与推理优化
- 模型量化与压缩
- 推理加速（vLLM、TensorRT-LLM 等）
- Speculative Decoding
- KV Cache 优化
- 服务化与负载均衡

### 7. 多模态与前沿
- 多模态模型架构
- 视觉语言模型
- 语音模型
- 长上下文模型
- 推理模型（o1 等）

### 8. 基础原理
- Transformer 架构
- 注意力机制
- 位置编码
- Tokenization
- 涌现能力与 Scaling Law

## 维度 B：问题类型

### 1. 方案设计
- 给定场景，设计完整解决方案
- 需要考虑约束条件、资源限制
- 示例："如何设计一个 Agent 评测系统？"

### 2. 指标设计
- 设计评估指标或评价体系
- 需要考虑指标的有效性、可操作性
- 示例："如何设计细粒度评测维度？"

### 3. 对抗测试 / 边界测试
- 构建高难度测试样本
- 暴露系统缺陷
- 示例："如何构建对抗评测样本？"

### 4. 根因定位
- 分析问题原因
- 调试与排查
- 示例："依赖链报错如何定位根因？"

### 5. 冲突决策
- 处理矛盾信息
- 设计决策机制
- 示例："人工评测与自动评测冲突怎么办？"

### 6. 成本优化
- 在资源约束下优化
- 权衡效果与成本
- 示例："不增加成本前提下提升检测能力？"

### 7. 回归测试 / 归因分析
- 模型迭代后的评测
- 定位能力退化点
- 示例："如何设计回归评测体系？"

### 8. 概念理解
- 解释原理或概念
- 比较不同方法
- 示例："什么是 RLHF？和 DPO 有什么区别？"

### 9. 代码实现
- 手写代码或伪代码
- 算法实现
- 示例："实现一个简单的 RAG 检索模块"

## 问题簇识别

同一份面经中，识别出问题之间的关联，形成"问题簇"：

### 识别规则

1. **同一技术领域**：多道题涉及同一领域
2. **同一问题链**：A 题是 B 题的前置或延伸
3. **同一场景**：多道题围绕同一业务场景

### 问题簇示例

**评测方法链条**：
- Q1（偏差验证）→ Q2（分布偏移校准）→ Q8（成本优化）

**Agent 评测链条**：
- Q3（细粒度维度）→ Q4（对抗样本）→ Q6（中间步骤）→ Q10（多 Agent 归因）

**工程化链条**：
- Q5（pipeline 可靠性）→ Q7（冲突决策）→ Q9（回归测试）
